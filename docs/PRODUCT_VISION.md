# Product Vision – Nexus Life

## Problem

Ludzie w 2026 żyją w chaosie informacyjnym:
- Mają 4–8 subskrypcji AI
- Notatki rozrzucone po Google Keep, Notion, notatniku, WhatsApp
- Paragony i faktury giną w galerii
- Nawyki śledzą w 3 różnych aplikacjach
- Boją się wysyłać prywatne dane do chmury

## Rozwiązanie

Jedna aplikacja, która:
1. Słucha głosu i automatycznie strukturyzuje życie
2. Trzyma wszystkie dane lokalnie (on-device)
3. Nigdy nie crashuje i nie gubi danych
4. Daje jeden czysty dashboard "Dzisiaj"

## Target user

- Osoby 25–45 lat
- Freelancerzy, studenci, młodzi rodzice, knowledge workers
- Ludzie, którzy już płacą za ChatGPT / Gemini, ale czują chaos
- Użytkownicy Androida (największy rynek + niższa średnia jakość konkurencji)

## Monetization

- Free: podstawowy voice capture + proste nawyki + lokalna baza
- Pro (19–29 zł/mies.): pełne AI, OCR paragonów, zaawansowane wyszukiwanie, backup cloud (opcjonalny, zaszyfrowany), multi-device sync
- Lifetime deal na start (promocja)

## Differentiation

- 100% offline-first + on-device AI
- Zero data loss guarantee (to nasza główna obietnica)
- Polski język od dnia 1 (duża przewaga lokalna)
- Minimalistyczny, szybki UI
